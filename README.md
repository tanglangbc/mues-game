Glowkeep — Lantern Tide is an original arcade game where a lantern keeper collects glowing pearls, dodges ink wisps, and clears six waves to reach the Crown Pearl. Move with WASD or the arrow keys, dash with Space or a mouse click, and restart with R.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
